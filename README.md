- 각 시험에서 이름을 입력하고 응시합니다. 완료 후 기기에 기록됩니다.

## 서버에 결과 기록하기 (Google Sheets + Apps Script)

1. Google 스프레드시트를 하나 생성하세요.
2. 메뉴의 확장 프로그램 > Apps Script를 엽니다.
3. 저장소의 google_apps_script.gs 내용을 편집기에 붙여 넣고 저장합니다.
4. 배포 > 새 배포 > 웹 앱: 실행 계정 '나', 접근 권한 '모든 사용자'로 배포합니다.
5. 배포가 만든 /exec URL을 복사합니다.
6. 저장소 recording_config.json 의 endpoint 값을 이 URL로 변경합니다.
7. 휴대전화에서 제출 후 시트의 results 탭에 기록된 행을 확인합니다.

보안: 결과 수집 URL은 공개되어 있으므로 누구나 임의의 기록을 전송할 수 있습니다. 이름 대신 별명을 권장하며, 실명·민감정보를 입력하지 마세요. 이 방식은 학습 진도 모니터링용이지 신뢰할 수 있는 온라인 시험 감독용이 아닙니다.

중요: 웹페이지의 전송은 브라우저 CORS 제약으로 서버 수신을 직접 확인하지 못합니다. 관리자 스프레드시트에서 행을 확인하세요. endpoint가 비어 있으면 전송하지 않고 로컬 저장만 합니다.
